# 强化 AI 开发规范与静态仓库自动检查

- **日期**：2026-11-25
- **作者**：ffbecn
- **工具**：Antigravity CLI
- **模型**：Gemini 4 Neon（High）

## 任务说明

更新 `AGENTS.md` 补齐防测试字符串碰撞假阳性规则与“连续两轮修复失败即撤销重审”的回退纪律；扩展 `.github/scripts/check_repo.py`，新增未来共享 ABI 头文件检查（禁止条件编译宏与硬件物理地址常量）并预留内核 ELF 残留符号自动检查能力（支持 `--check-elf` 与迁移后自动激活）。

## Prompt

~~~text
3. 加强 AI 开发规范和自动检查
- 更新 AGENTS.md：
  - 测试不能因为测试字符串和程序内置字符串相同，就出现假阳性。
  - 同一个问题连续两轮修复失败，就撤销当前补丁，回到干净状态重新分析，不能不断叠加补丁。
- 更新 check_repo.py：
  - 检查未来新增的共享 ABI 头文件，禁止使用条件编译宏和硬件物理地址常量。
  - 预留 ELF 符号检查功能，以后文件系统和驱动迁出内核后，可以自动检查内核是否还残留相关代码。
~~~
