# LoongArch 副核唤醒实测验证与进程槽位分区预留

- **日期**：2026-11-25
- **作者**：ffbecn
- **工具**：Antigravity CLI
- **模型**：Gemini 4 Neon（High）

## 任务说明

针对两项关键架构设计开展实测核验与代码落地：
1. 编写独立最小 LoongArch64 裸机探针，在 `qemu-system-loongarch64 -machine virt -smp 3` 上实测验证副核引导、IOCSR IPI 唤醒 `idle 0` 能力及 10ms 定时备用唤醒与 100ms 系统时钟分频校准，并补齐此前缺失的 `hal_boot_secondary()` 使龙芯 3 核真正上线运行；
2. 落地 `NPROC = 72` 进程表硬分区设计（`NPROC_SVC = 8` 独占 `proc[0..7]` 供微内核服务使用，`NPROC_USER = 64` 独占 `proc[8..71]` 供普通用户进程使用），确保用户态 `fork` 耗尽进程槽时绝不影响服务重启。

## Prompt

- 进程数量限制： 系统预留 8 个进程槽位给微内核服务，普通用户进程最多使用 64 个，避免用户程序把服务重启所需的槽位全部占满。
